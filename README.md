# Памятка ДПС — веб-версия

Автономное PWA-приложение, созданное по извлечённым ресурсам Android APK.

## Что внутри

- 464 экранных маршрута исходного справочника;
- все Android-макеты и строковые ресурсы;
- поиск по текстам статей;
- навигация между экранами;
- PWA-манифест и Service Worker для офлайн-доступа ко всему справочнику после первого запуска.

## Проверка на компьютере

Нужен любой статический веб-сервер. Например, при установленном Python:

```powershell
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Установка на iPhone

1. Разместите содержимое этой папки на HTTPS-хостинге.
2. Откройте сайт в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран “Домой”».
4. Включите «Открывать как веб-приложение» и нажмите «Добавить».

Для изменения существующих статей редактируйте соответствующий XML-макет в `assets/res/layout/`. Для надёжного редактирования и добавления новых экранов предпочтительно развивать веб-структуру в `app.js` и `data/routes.json` вместо ручного изменения Android-артефактов.
